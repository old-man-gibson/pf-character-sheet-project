Embedding a character sheet

This page uses serif type, a cream background, and some intentionally awful global rules (pink dashed tables, lime buttons, red input borders). The sheet below is unaffected — everything renders inside a shadow root, so host styles and sheet styles cannot collide in either direction. 

<script type="module" src="/app/js/sheet-element.js"></script>

<character-sheet
    src="/data/characters/your-character.json"
    role="player"
    theme="light"
    storage-key="campaign:your-character"></character-sheet>

A src URL is the usual way in; a host that already holds the document can set the character property instead. This demo does the latter, with a blank character built on the spot, so it works with nothing bundled.

Theming is done with custom properties, which do cross the shadow boundary — that is the supported way to restyle an embedded sheet: 

character-sheet { --cs-accent: #7b3f9d; --cs-radius: 14px; }
