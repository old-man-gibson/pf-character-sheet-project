Import this character

Replacing keeps that character’s slot and its history. Its current version is filed as a checkpoint named “before import” first, so nothing is lost — open History on the sheet to go back to it.

Remove this character?

It leaves the picker, and its sheet, saved version and history go with it. Undo stays on offer in the banner, and the character is kept out of sight for a day in case you change your mind — after that it is gone. If you want a copy for good, cancel and use Export JSON on the sheet first.

New character

A blank sheet: 10 in every score, the standard skill list, 6 hit points a level to start, and slots waiting for traits, race traits and perks. Classes, level plan, gear and everything else are yours to enter. Characters start at 3rd or higher.

Start a character from nothing: press + New, give it a name and a level, and you get a blank sheet with 10 in every score and the standard skill list; it is saved in this browser exactly like an import.

Add your own character: in Google Sheets choose File → Download → Microsoft Excel (.xlsx), then press + Import — or drop the file anywhere on this page. The workbook is read here in your browser and thrown away once it has been transcribed; it is never uploaded. A .json this app exported can be dropped back the same way.

Everything is saved to this browser only — nobody else sees it, and clearing your browser data clears it.

Saving and going back: your edits are kept as you make them, so a closed tab loses nothing. Save marks the version the sheet opens on, and anything edited after it is offered back to you next time rather than assumed. A snapshot is taken automatically every 20 changes and the last 5 are kept; a checkpoint you name — “before respec” — is kept until you delete it. History lists all of them. “Reset” goes back to the character as imported and keeps your named checkpoints.

Export JSON downloads one character, which is how you send a build to someone else; Export all downloads every character in the picker as a .zip of those same files. Tick GM / inspector view to reveal the Formula Audit tab, which lists every player-authored formula as plain text.
